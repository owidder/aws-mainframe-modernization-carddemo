MVSWAIT-TIME PARM-VALUE

COBSWAIT.CBL

A utility program that introduces a controlled pause (wait/delay) into batch processing workflows for a specified duration expressed in centiseconds.

COBSWAIT accepts a numeric duration value (in centiseconds) as input from the system input stream (SYSIN) and instructs the batch job to wait for that precise period before continuing. This is achieved by delegating the actual wait operation to the MVSWAIT subprogram, which interfaces with the underlying mainframe operating system timing facilities. The program is used to coordinate timing between batch jobs or job steps, for example to introduce deliberate delays between archiving, unloading, or loading operations (such as those performed by DBUNLDGS, PAUDBUNL, and PAUDBLOD) to avoid resource contention or to synchronise dependent processes. Once the wait period has elapsed, the program terminates normally, allowing the calling job stream to proceed.

Business Rules
  • Wait duration must be supplied externally via SYSIN at runtime, making the delay configurable without code changes.
  • Duration is expressed in centiseconds (hundredths of a second), allowing fine-grained control over timing intervals in batch job streams.
  • The program introduces no data processing logic of its own; its sole business function is timing control within a broader batch workflow.
  • Used to prevent race conditions or resource conflicts between dependent batch jobs such as database unload, archive, and reload operations in the CardDemo system.

This value is passed directly to the operating system's wait routine and determines the precise timing gap inserted between dependent batch operations — such as a database unload, archive, or reload — to prevent resource conflicts or race conditions in the CardDemo batch workflow.
