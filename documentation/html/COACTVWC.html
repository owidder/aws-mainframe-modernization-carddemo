COACTVWC.CBL

This program allows bank staff to view the full details of a credit card account by entering an account number, retrieving and displaying associated account and customer information on screen.

A bank staff member enters a credit card account number on the Account View screen. The program validates the input (ensuring it is numeric, non-zero, and 11 digits), then looks up the account in the card cross-reference file, retrieves the full account record from the account master file, and retrieves the associated customer record from the customer master file. The combined account and customer details are then displayed on screen for the staff member to review. From this view screen, the staff member can navigate to related functions such as the card list, card detail, card update, or return to the main menu.

Business Rules
  • The account number entered must be exactly 11 digits, numeric, and non-zero; otherwise an error message is displayed and the staff member is prompted to re-enter.
  • The account number must exist in the card cross-reference file (CXACAIX); if not found, the staff member is informed that the account cannot be located.
  • The account must exist in the account master file (ACCTDAT); if not found, an appropriate error is displayed.
  • The customer associated with the account must exist in the customer master file (CUSTDAT); if not found, an error is displayed indicating the customer record is missing.
  • Only the Enter key and PF3 (exit/back) are treated as valid keystrokes; any other function key press is ignored and treated as Enter.
  • Pressing PF3 returns the staff member to the previously calling program/transaction (or the main menu if no prior context exists), ensuring consistent navigation within the application.
  • The program is a read-only view; no account or customer data is modified by this program — updates are delegated to COACTUPC and card updates to COCRDUPC.
  • From the account view screen, staff can navigate to the card list (COCRDLIC) or card detail/update (COCRDSLC/COCRDUPC) screens for further action on the account's cards.
