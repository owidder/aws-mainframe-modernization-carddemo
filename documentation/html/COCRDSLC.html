COCRDSLC.CBL

This program allows bank staff to search for and display the details of a specific credit card by entering an account number and/or card number as search criteria.

The program presents a search screen where bank staff can enter an account number (11 digits) and optionally a card number (16 digits) to locate a specific credit card record. It validates the entered search criteria, ensuring the account number is a non-zero numeric value and the card number, if provided, is a valid 16-digit numeric value. Upon successful validation, it retrieves the matching credit card details from the card database and displays them on screen, including card number, cardholder name, CVV, expiry date, and card status. The program integrates with a card list program (COCRDLIC) to support navigation from a list view to a detail view, and allows users to exit back to the calling program or main menu via PF3.

Business Rules
  • Account number is mandatory and must be an 11-digit non-zero numeric value; blank or zero account numbers are rejected with an appropriate error message.
  • Card number is optional, but if supplied it must be a valid 16-digit numeric value; non-numeric or incorrectly sized card numbers are rejected.
  • At least one search criterion (account number) must be provided; submitting the screen with no input is not permitted.
  • If the account number does not exist in the card cross-reference database, an error is displayed indicating no cards were found for that account.
  • If the combination of account number and card number does not match any record, the user is informed that no cards were found for the given search condition.
  • Pressing PF3 exits the program and returns the user to the previously calling program or the main menu if no calling program is recorded.
  • When navigating from the card list screen (COCRDLIC), the account and card number are passed automatically and card details are retrieved without requiring manual re-entry.
  • Only the Enter key and PF3 are treated as valid function keys; any other key press is treated as an Enter key action to prevent unintended navigation.
