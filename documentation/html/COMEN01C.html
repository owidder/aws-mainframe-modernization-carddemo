COMEN01C.CBL

Presents and manages the main navigation menu for regular (non-admin) users of the CardDemo credit card management system, allowing them to select and launch available functional modules.

Upon entry, the program validates that a user session exists (communication area is populated); if not, it redirects the user back to the sign-on screen. For authenticated regular users, it dynamically builds and displays a numbered menu of up to 12 available options sourced from the shared communication area, showing the current date and time in the screen header. When the user selects an option by entering a number and pressing Enter, the program validates the selection, enforces access control (blocking admin-only options from regular users), and transfers control to the corresponding functional program via CICS XCTL. Pressing PF3 returns the user to the sign-on screen, and any unsupported key press results in an error message being displayed on the menu screen.

Business Rules
  • A valid authenticated session (non-zero communication area) must exist before the menu is displayed; otherwise the user is redirected to the sign-on screen.
  • Regular users are explicitly blocked from selecting menu options designated as 'Admin Only' (CDEMO-MENU-OPT-USRTYPE = 'A'); an access-denied message is displayed if attempted.
  • Only numeric option values within the valid range (1 to CDEMO-MENU-OPT-COUNT) are accepted; non-numeric, zero, or out-of-range entries result in a validation error message.
  • Menu options mapped to programs with a name beginning with 'DUMMY' are treated as placeholder features not yet implemented, and the user is informed they are 'coming soon' without any program transfer occurring.
  • Menu options mapped to the program 'COPAUS0C' are subject to an additional runtime availability check (CICS INQUIRE); if the program is not installed, the user is informed rather than an error being thrown.
  • Pressing PF3 at any time returns the user to the sign-on screen (COSGN00C), effectively ending the current session navigation.
  • Any key press other than Enter or PF3 is treated as invalid and results in an error message being displayed on the menu screen without any navigation occurring.
  • The menu supports a maximum of 12 displayable options; any options beyond 12 in the communication area are silently ignored.
