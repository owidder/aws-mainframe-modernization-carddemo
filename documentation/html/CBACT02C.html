CBACT02C.CBL

Batch program that reads and prints all credit card records from the card master file for reporting or audit purposes.

This batch program performs a sequential read of the entire card master file (an indexed VSAM KSDS dataset) and outputs every card record to the system log or print destination. It opens the file, iterates through all records from beginning to end, displays each card record in full, then closes the file and terminates. The program is designed for operational reporting, data verification, or audit trail generation of all credit cards held in the CardDemo system.

Business Rules
  • All credit card records in the card master file must be processed sequentially from first to last without skipping any record.
  • Every card record read successfully must be displayed/printed in full, providing a complete snapshot of all cards in the system.
  • If the card master file cannot be opened, the program must terminate abnormally (abend) rather than proceed with no data — ensuring no silent failures in reporting.
  • Any unexpected read error (other than normal end-of-file) causes an immediate abnormal termination with abend code 999, preventing incomplete or misleading output.
  • The program is read-only — it does not modify, update, or delete any card records, making it safe for use in audit and compliance reporting contexts.
