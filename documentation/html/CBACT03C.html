CBACT03C.CBL

Read and print all card-to-account cross-reference records from the cross-reference file as a batch reporting/audit utility.

This batch program sequentially reads every record in the card account cross-reference file (XREFFILE), which maps credit card numbers to their associated account identifiers. For each record found, it displays the cross-reference data to the system output (SYSOUT/job log), effectively producing a full listing of all card-to-account linkages held in the system. The program processes all records from start to finish in sequential order and terminates cleanly after the last record is read. If any file I/O error occurs during open, read, or close operations, the program abends with a standard error code (999) to signal the failure to operations staff.

Business Rules
  • Every card-to-account cross-reference record in the file must be read and reported — no filtering or selection criteria are applied; this is a full file dump.
  • The credit card number (16 digits) is the unique key for each cross-reference record and determines the sequential read order.
  • If the cross-reference file cannot be opened, read, or closed successfully, the program must abend immediately with code 999 — no partial or silent failures are permitted.
  • End-of-file is a normal and expected condition (status '10') and does not constitute an error; all other non-zero statuses are treated as processing failures.
  • The program is read-only — it does not create, update, or delete any records, ensuring the integrity of the cross-reference data is preserved during the reporting run.
