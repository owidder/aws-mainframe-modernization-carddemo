COUSR00C.CBL

Provide administrators with a paginated list of all system users, allowing them to select a user for update or deletion.

This program retrieves and displays all registered users from the User Security file (USRSEC) in a paginated list of up to 10 users per screen, enabling administrators to browse the full user population. Administrators can navigate forward (PF8) and backward (PF7) through pages of users, or search by entering a specific User ID to position the list. For each displayed user, the administrator can enter a selection code ('U' to update or 'D' to delete) next to a user record, which transfers control to the appropriate maintenance program (COUSR02C for update, COUSR03C for delete). The program is accessible only to authenticated admin users, returning unauthenticated sessions to the sign-on screen and returning authenticated admins to the admin menu (COADM01C) on PF3.

Business Rules
  • Only authenticated administrator sessions may access this program; unauthenticated users are redirected to the sign-on screen (COSGN00C).
  • A maximum of 10 user records are displayed per page.
  • Valid selection actions are 'U' (Update) and 'D' (Delete) only; any other selection code is rejected with an error message.
  • Only one user may be selected for action at a time per screen interaction.
  • Administrators cannot navigate before the first page (PF7 blocked at page 1) or beyond the last page (PF8 blocked when no further records exist).
  • Selecting 'U' transfers control to COUSR02C (user update program); selecting 'D' transfers control to COUSR03C (user delete program).
  • PF3 returns the administrator to the admin main menu (COADM01C) without performing any user action.
  • An optional User ID search field allows the administrator to position the list starting from a specific user, enabling direct navigation within a large user population.
