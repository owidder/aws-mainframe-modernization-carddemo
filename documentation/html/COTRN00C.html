COTRN00C.CBL

Display a paginated list of credit card transactions from the TRANSACT file, allowing users to browse and select individual transactions for detailed viewing.

This program presents a scrollable, paginated transaction list screen (up to 10 transactions per page) to bank staff or cardholders, reading records from the TRANSACT file sequentially. Users can navigate forward (PF8) and backward (PF7) through pages of transactions, or enter a specific Transaction ID to start browsing from that point. When a user selects a transaction by entering 'S' next to it, the program transfers control to COTRN01C to display the full transaction detail. The program maintains page state (first/last transaction ID on current page, page number, next-page availability flag) in the communication area to support bidirectional pagination across CICS interactions.

Business Rules
  • A maximum of 10 transactions are displayed per page; the program reads exactly 10 records forward or backward from the current browse position.
  • Only the selection value 'S' (uppercase or lowercase) is valid when selecting a transaction; any other value results in an error message 'Invalid selection. Valid value is S'.
  • A Transaction ID used as a search/start key must be numeric; non-numeric input is rejected with the message 'Tran ID must be Numeric'.
  • Forward navigation (PF8) is blocked when already on the last page of transactions, displaying 'You are already at the bottom of the page'.
  • Backward navigation (PF7) is blocked when already on the first page (page number not greater than 1), displaying 'You are already at the top of the page'.
  • If no communication area is present (EIBCALEN = 0), the user is redirected to the sign-on screen (COSGN00C), enforcing authenticated access.
  • Selecting a transaction (flag 'S') causes an immediate transfer of control (XCTL) to COTRN01C for transaction detail viewing, passing the selected transaction ID via the communication area.
  • PF3 returns the user to the main menu program (COMEN01C), providing standard navigation back to the application menu.
  • The program preserves the first and last transaction IDs of the current page in the communication area to enable accurate bidirectional pagination across multiple CICS pseudo-conversational interactions.
