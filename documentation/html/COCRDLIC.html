COCRDLIC.CBL

This program displays a paginated list of credit cards to bank staff, filtered by account or showing all cards depending on the user's administrative privileges.

When a bank staff member accesses the credit card list screen, the program retrieves and displays up to 7 credit cards per page, showing each card's account number, card number, and card status. If the user is an administrator with no specific account context, all credit cards in the system are listed; if the user is a non-admin or an account context has been passed, only cards associated with that specific account are shown. The staff member can navigate through pages of results using function keys (PF7/PF8 for previous/next page) and can select an individual card record to either view its full details (by typing 'S') or update it (by typing 'U'), which transfers control to the card detail or card update program respectively. The program maintains pagination state between interactions by storing the first and last card keys of the currently displayed page in the communication area.

Business Rules
  • Administrator users can view all credit cards in the system; non-administrator users can only view cards associated with a specific account passed in the communication area.
  • A maximum of 7 credit card records can be displayed on a single screen page at one time.
  • The user may only select one card record at a time for viewing or updating; selecting more than one simultaneously is rejected with an error message.
  • Valid action codes for a card row are 'S' (view detail) or 'U' (update); any other non-blank entry is rejected as an invalid action code.
  • Navigation is controlled via function keys: PF7 scrolls back to the previous page, PF8 advances to the next page, PF3 exits the list and returns to the calling program or menu.
  • Any function key other than Enter, PF3, PF7, or PF8 is treated as invalid and defaulted to Enter behaviour.
  • If no credit card records are found matching the search or filter criteria, a 'NO RECORDS FOUND' message is displayed to the user.
  • Pagination state (first card key, last card key, current page number, and whether a next page exists) is preserved in the communication area between screen interactions to support forward and backward navigation.
  • When entering the program fresh (not returning from a detail or update screen), pagination state is reset to the first page.
  • Selecting 'S' on a card transfers the user to the card detail view program (COCRDSLC); selecting 'U' transfers the user to the card update program (COCRDUPC), passing the selected card's context.
