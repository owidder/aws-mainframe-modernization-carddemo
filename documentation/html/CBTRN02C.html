CBTRN02C.CBL

Das Programm "CBTRN02C" dient der Verarbeitung und Aufnahme von täglichen Kreditkartentransaktionen. Es liest Transaktionsdaten aus einer Daily-Transaktion-Datei ein, validiert diese Daten und postet sie dann auf die entsprechenden Kundenkonten in einer Account-Datei.

Der Geschäftsprozess beginnt mit der Öffnung der Daily-Transaktion-Datei. Das Programm liest Transaktionsdaten ein und überprüft deren Gültigkeit. Wenn die Daten valid sind, werden sie auf die entsprechenden Kundenkonten in einer Account-Datei postet. Bei ungültigen oder fehlerhaften Daten wird eine Rejection-Datei verwendet. Dies geschieht in einem Batch-Prozess mit der Unterstützung von CICS (Customer Information Control System).

Business Rules
  • Transaktionen müssen eindeutig und korrekt sein, um auf den richtigen Kundenkonten postet zu werden.
  • Fehlende oder ungültige Daten führen zur Erstellung einer Rejection in der Rejects-Datei.
  • Die Transaktionsdaten müssen regelmäßig und ohne Fehler aus verschiedenen Quellen eingeholt werden.
Files / Data Sources
DALYTRAN-FILE Die Daily-Transaktion-Datei enthält die Transaktionsdaten, die täglich aus den Kassen und anderen Transaktionsquellen eingeholt werden.
TRANSACT-FILE Die Output-Datei für Transaktionen, auf der validierte Daten postet.
XREF-FILE Die Cross Reference-Datei dient zur Zuordnung von Transaktionsdaten zu den richtigen Kundenkonten.
DALYREJS-FILE Die Daily Rejects-Datei wird verwendet, um ungültige oder fehlerhafte Daten aufzubewahren.
ACCOUNT-FILE Die Account-Datei enthält die Details aller aktiven Kreditkartenkonten.
