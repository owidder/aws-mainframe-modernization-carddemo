CBCUS01C.CBL

Batch program that sequentially reads and prints all customer records from the customer master file for reporting or audit purposes.

This program opens the customer master file and reads every customer record sequentially from start to finish, displaying each record to the system output. It is the customer data equivalent of CBACT02C (which does the same for card records), serving as a full customer data extract or audit report. The program handles end-of-file gracefully and will abnormally terminate (ABEND) with a diagnostic code if any unexpected file I/O error occurs, ensuring data integrity issues are surfaced immediately.

Business Rules
  • Every customer record in the master file must be read and printed — no filtering or selection criteria are applied, ensuring a complete audit trail.
  • The customer file must be accessible and openable; failure to open the file results in an immediate abnormal program termination (ABEND), preventing partial or misleading output.
  • Any unexpected I/O error during record reading (other than normal end-of-file) causes an immediate ABEND with diagnostic status codes, ensuring data integrity issues are not silently ignored.
  • Records are processed in customer ID sequence (sequential access on a KSDS VSAM file), providing an ordered, reproducible output suitable for reconciliation or audit.
  • Normal end-of-file is the only acceptable termination condition for the read loop; all other conditions are treated as errors.
